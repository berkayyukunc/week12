# EE 471 Modern Software Development Practices and Technologies - Week 12

This repository contains the in-class exercise for Week 12.

## Project Structure
- `djangotutorial/`: The Django backend server.
- `.github/workflows/`: CI/CD workflows for Lint Testing, Semantic Versioning, and Continuous Deployment.
- `release.config.js`: Configuration for `semantic-release`.
- `publish/bump_version.py`: Custom version bumping script.
- `VERSION`: Stores the current release version of the application.
- `CHANGELOG.md`: Generated changelog tracking all release notes.
